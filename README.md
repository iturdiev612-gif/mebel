# Мебель дома

React-каталог мебели на русском языке. Проект находится в папке `first-mebel`.

## Запуск

Дважды нажмите `Запустить сайт.cmd` или выполните `npm start` в этой папке.
Адрес: http://localhost:3000. Остановить сервер можно сочетанием Ctrl+C.
Если вы перенесли проект на другой компьютер, сначала выполните `npm install`.

## Возможности

- 25 предоставленных фотографий в 5 категориях: диваны, спальни, кухни, шкафы, прихожие.
- Поиск по названию, типу, цвету и артикулу; категории, сортировка, загрузка следующих моделей.
- Просмотр товара с описанием и артикулом.
- Корзина с количеством и удалением товаров; избранное; светлая и тёмная темы.
- Корзина, избранное и тема сохраняются в браузере.
- Бронирование одной модели или всей корзины: имя, страна, номер, город, желаемая дата, комментарий.
- Фиксированный код страны: Кыргызстан +996 и 9 цифр; Россия +7 и 10 цифр; Казахстан +7 и 10 цифр. Поле принимает только цифры; код нельзя стереть. Вставка полного номера со своим кодом поддерживается.
- WhatsApp открывает подготовленное сообщение владельцу +996 704 665 501. Покупатель сам отправляет его. Бронь подтверждает владелец; серверного резервирования и оплаты нет.
- Цены не назначены и не отображаются: владелец и покупатель договариваются напрямую.

## Изменение данных

`src/catalog.js` содержит все модели и номер владельца в CONTACT. Названия моделей и артикулы условные: при необходимости замените их на названия владельца. Неизвестные характеристики не придуманы; размеры указаны только там, где они видны на исходных фотографиях. Изображения находятся в `public/images` и не загружаются с внешних сайтов.

Номер владельца: CONTACT.display для отображения, CONTACT.phone для звонков, CONTACT.whatsapp без плюса для WhatsApp.

## Проверка и сборка

`npm test -- --watchAll=false --runInBand` — автоматические проверки.
`npm run build` — готовая версия в папке `build`.

Сборку можно размещать на статическом хостинге. Сайт создан локально; публичного размещения в интернете не выполнено.
